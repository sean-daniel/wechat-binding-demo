# 微信通知绑定 · 静态原型

贵州省级学籍综合服务网「微信通知绑定」页面的纯静态 Demo。

在线预览：https://sean-daniel.github.io/wechat-binding-demo/

## 演示路径

- 默认未绑定：点击二维码模拟扫码，1.2 秒后进入已绑定状态
- 已绑定：可点击「换绑微信」或「解绑微信」查看对应流程
- 快捷状态：`index.html#bound`、`index.html#rebind`、`index.html#unbound`

## 说明

- 页面数据均为 Mock，不包含真实用户信息。
- 未对接微信接口，二维码、OpenID、UnionID 均为演示数据。
- 左侧菜单为顶级菜单项「微信通知绑定」，与现有后台布局一致。
